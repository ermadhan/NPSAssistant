# Securities

The Securities screen estimates the stocks and bonds represented by supported NPS schemes. It applies security weights from official pension-fund portfolio disclosures to the value of the selected scheme holdings.

These figures are estimates of underlying exposure, not securities held directly in the subscriber's account.

## Refresh official disclosures

Choose **Refresh ICICI portfolio**, **Refresh HDFC portfolio**, or **Refresh LIC portfolio** to fetch that manager's latest supported disclosure. A success or failure message appears in the status area. Stored disclosures are local to the app.

The screen lists the dates of the disclosures currently being used. Refreshing a manager updates its stored disclosure, and the exposure view uses the latest stored disclosure available for each supported manager.

## Read the exposure results

- **Look-through coverage** compares the value covered by supported disclosures with the total value selected by the filters.
- The summary cards group estimated exposure by instrument type.
- The table lists instrument type, security, ISIN, industry, estimated exposure, and portfolio percentage.
- **Not included in look-through** identifies schemes or managers not covered by the currently supported disclosures.

The view supports E, C, and G schemes for Tier 1 and Tier 2 from ICICI, HDFC, and LIC Pension Funds. Other managers and unsupported schemes are not included, so review the coverage percentage before interpreting the table as a complete portfolio.

## Filters and historical views

Name, Tier, Scheme, and Financial year filters limit the holdings used to estimate exposure. For a historical financial year, the app applies the latest stored disclosure weights to the selected statement values. Disclosure dates can therefore differ from the statement date, as noted on the screen.

If no disclosure has been downloaded, use the manager refresh buttons. If coverage is incomplete, review the unsupported-schemes note as well as the exposure table.

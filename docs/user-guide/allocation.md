# Allocation

Allocation summarizes portfolio value by account, tier, and scheme asset class. It is useful for comparing how much of the family portfolio is in each category.

## By tier and asset class

The first table shows each account's Tier 1 and Tier 2 values across:

- Equity
- Corporate
- Government
- Alternative

Each displayed amount is current value. In the current view, the cell also shows estimated invested amount. A tilde (`~`) marks an incomplete estimate. When a particular account/tier has no value in the selected asset categories, it may not have a row in this table.

## Asset-class and portfolio totals

The second table shows each account and the family total by asset class, plus the overall portfolio value. In the current view, invested amount appears below each value. Historical-year views show the selected statement snapshot and omit invested amounts because that view does not calculate a historical invested basis.

Current allocation values use the latest available NAV, falling back to the statement NAV when a latest NAV is unavailable. The explanatory note below the tables indicates when invested data is partial.

## Narrow the view

Use Name, Tier, Scheme, and Financial year filters to focus the allocation on one account holder, tier, scheme, or statement year. The tables can be scrolled horizontally if the full width does not fit your window.
